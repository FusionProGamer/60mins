# AI Campus Helpdesk — Presidency University
**Technopia 2.0 · Build It in 60 Minutes**

A chat helpdesk where students ask campus questions in natural language and get answers grounded **only** in the supplied sample university information. If the answer isn't in that data (e.g. the exact date of an exam), it says so instead of inventing one.

## AI model / API used
- **Google Gemini API** (`gemini-3.8-flash` by default, change with `GEMINI_MODEL`).
- Called from the **Flask backend** (`app.py`), so the API key is never exposed to the browser.

## How AI is integrated
1. `knowledge.py` holds the sample university information (the only knowledge source).
2. On each question, the backend sends the knowledge base + strict grounding rules as the system prompt, plus the last few chat turns (so follow-ups work).
3. The model **understands the intent** (typos, slang, rephrasing, e.g. "my room's fan is broken" → Hostel), then replies with structured JSON: `answer`, `category`, `found`, `suggestions`.
4. `found: false` triggers the "Not in the information I have" state in the UI, and the prompt forbids inventing dates, times, emails, phone numbers or percentages.
5. Prompt-injection attempts ("ignore your rules…") are explicitly refused in the system prompt.

No hard-coded Q&A pairs: the topic tiles/starter chips only pre-fill a question, and every answer is generated by the model.

## Features
- Chat UI with topic sidebar, starter questions, typing indicator, timestamps, **Clear chat**, and **Was this helpful?** feedback
- Handles academics, attendance, examinations, placements, library, hostel, administration and events
- Unknown-query handling with an amber "not available" state
- Follow-up suggestion chips generated by the AI
- Input validation, per-IP rate limiting, friendly error messages
- Responsive (desktop, tablet, phone), keyboard-accessible

## Run locally
### Windows (PowerShell)
```bash
cd campus-helpdesk
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
# Open .env and set GEMINI_API_KEY to a Google AI Studio Gemini API key.
python app.py
```

If PowerShell blocks virtual-environment activation, run `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` in that terminal, then activate again. Alternatively, skip activation and run `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` followed by `.\.venv\Scripts\python.exe app.py`.

### macOS / Linux
```bash
cd campus-helpdesk
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
# Open .env and set GEMINI_API_KEY to a Google AI Studio Gemini API key.
python app.py
```

Open http://127.0.0.1:5000. Create a Gemini API key in Google AI Studio. The key belongs in the server-side `.env` file only; never put it in browser JavaScript or commit `.env`.
